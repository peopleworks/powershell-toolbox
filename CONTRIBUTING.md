# Contribuir / Contributing

Se agradecen scripts pequeños, independientes y con ejemplos reproducibles. Antes de proponer un cambio:

1. Use parámetros para rutas, servidores, DSN y usuarios. Los ejemplos deben usar nombres ficticios.
2. No incluya contraseñas, tokens, cadenas de conexión, dominios privados, datos de clientes ni resultados generados con ellos.
3. Documente requisitos de sistema y efectos de escritura. Prefiera salida en objetos PowerShell.
4. Ejecute `./tests/Smoke.ps1` y revise manualmente los archivos que vaya a confirmar.

Small, standalone scripts with reproducible examples are welcome. Parameterize paths and connection details, use fictional examples, document requirements and writes, and keep credentials and customer data out of commits.
