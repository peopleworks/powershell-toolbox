Primeros pasos — qué instalar

Configura tu entorno para ejecutar los scripts de PowerShell Toolbox.

1

Instalar PowerShell 7

La mayoría de los scripts requieren PowerShell 7 (multiplataforma).

winget install Microsoft.PowerShell
2

Permitir ejecución de scripts

En Windows, habilita la ejecución de scripts locales firmados o remotos de confianza.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
3

Instalar módulo Az (Azure)

Los scripts de Azure requieren el módulo Az y Connect-AzAccount.

Install-Module Az -Scope CurrentUser
Connect-AzAccount
4

Instalar dbatools (SQL Server)

Los scripts de SQL Server usan dbatools.

Install-Module dbatools -Scope CurrentUser
5

AWS Tools for PowerShell (opcional)

Los scripts de AWS requieren AWS.Tools.Common y credenciales configuradas.

Install-Module AWS.Tools.Installer -Scope CurrentUser
6

Controladores ODBC (opcional)

Instala los controladores ODBC de las bases de datos que quieras probar: MySQL, PostgreSQL, Oracle.

# Ejemplo: MySQL ODBC Driver 8.0
# Descarga desde dev.mysql.com
7

Ejecutar un script de ejemplo

Desde la raíz del repositorio, en PowerShell 7, prueba cualquiera de los 100 scripts.

./scripts/monitor/Test-HttpAttack.ps1 -LogPath "C:\inetpub\logs\LogFiles\W3SVC1"
